System Architecture & Pipeline Mechanics

Relay is an autonomous research assistant designed to answer technical questions strictly from a library of 3 arXiv papers without hallucinations, even during sudden traffic spikes.

1. Understand & Query Expansion

Generates focused technical search keywords using a compact model call. Automatically bypassed when system pressure crosses 70% to conserve API quota.

2. BM25 Chunk Retrieval

Indexed across 120 pages. Evaluates question word coverage and TF-IDF relevance across the three arXiv PDFs.

3. Coverage Branching Gate

Computes coverage overlap. If passages lack necessary information, immediately branches to safe refusal rather than guessing.

4. Speculative Streaming

Streams answer tokens with dynamic buffering. Holds back negative phrases to prevent contradictory partial streams.

5. Citation Verification Tool

Validates that every claim citation [n] and quoted text exists verbatim in the retrieved passages. Loops once to re-draft if check fails.

Zero Downtime Policy

When daily budget is exhausted at 3 PM, serves instant extractive quotes straight from paper text in <130 ms with 0 API tokens consumed.
