How to Use

Type any question about the 3 research papers or click any curated question chip. Watch the 5-stage pipeline execute each millisecond live. Click citation tags [1], [2] or expand the passage drawer to view the exact arXiv page and text excerpts.

2

The 5-Stage Resilient Pipeline

1. Understand: Generates search keywords via small model call (skipped automatically when system pressure exceeds 70%).
2. Retrieve: BM25 + TF-IDF chunk indexing across Attention Is All You Need (v7), Moshi (v1), and Dynamic Chunking (v2).
3. Decide: Evaluates question-passage coverage. If the question cannot be answered from the papers, branches immediately to refusal to prevent hallucination.
4. Draft: Streams candidate answer token-by-token while buffering potential negative markers.
5. Verify: Independent tool call verifies [n] citations and quoted spans exist in paper text. Loops once to re-draft if check fails.

3

Graceful Degradation (Zero Users Dropped)

• Full Mode: Full query expansion + full synthesis + verification.
• Lite Mode: When RPM/TPM load exceeds 70%, sheds query expansion and halves retrieval chunks to maintain responsiveness.
• Quick Extractive Mode: At 3 PM when daily budget is exhausted (RPD limit), serves instant extractive citations straight from arXiv papers with 0 API tokens and <100ms latency!

4

How This Library Misleads Naive Retrievers

1. Omnipresent Vocabulary: "Attention" appears hundreds of times across all three papers, pulling irrelevant Dynamic Chunking passages for Transformer questions.
2. Fragmented Tables: PDF extraction splits numerical values (e.g. BLEU scores or parameter counts) across chunk boundaries.
3. Bibliography False Positives: Questions about authors pull reference citations rather than original methodology.
